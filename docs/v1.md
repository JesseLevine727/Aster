# Aster v1.0 frozen specification

Status: **frozen** at Phase 13. This document is the single authoritative
contract for the Aster v1.0 SoC. It describes what is implemented and verified,
not aspirations. Any change to an address, register, ABI constant or
instruction encoding described here is a v2 change and must not be made on the
v1.0 line.

Scope: 2× PicoRV32 RV32IMA harts, private L1 I/D caches, MSI-like coherence
over shared RAM, DMA, the Xasterdot8 packed-INT8 instruction, a 4×4 INT8 NPU,
UART, performance counters, a machine timer and a per-hart interrupt
controller. Shared L2 is **not** in v1.0; see [Known limitations](#known-limitations).

## 2. Address map

Both tops share the low ROM/RAM windows and the `0x2000_0000` MMIO region. The
legacy `aster_minimal` map is preserved for Phases 1–4; the coherent top
repurposes RAM and the reserved MMIO pages.

### 2.1 Legacy `aster_minimal`

| Region | Start | End | Size | Access |
| --- | ---: | ---: | ---: | --- |
| Boot ROM | `0x0000_0000` | `0x0001_0000` | 64 KiB | RX |
| Main RAM | `0x1000_0000` | `0x1001_0000` | 64 KiB | RWX |
| UART | `0x2000_0000` | `0x2000_1000` | 4 KiB | RW |
| Timer | `0x2000_1000` | `0x2000_2000` | 4 KiB | reserved |
| Interrupt controller | `0x2000_2000` | `0x2000_3000` | 4 KiB | reserved |
| Performance counters (legacy ABI 2) | `0x2000_3000` | `0x2000_4000` | 4 KiB | RW |
| DMA | `0x3000_0000` | `0x3000_1000` | 4 KiB | reserved |
| INT8 NPU | `0x4000_0000` | `0x4000_1000` | 4 KiB | reserved |

Unmapped data reads return zero and bypass caches; unmapped instruction fetches
trap. ROM stores are ignored. RAM reserves a 4 KiB stack at the top.

The atomic fabric only permits instruction fetches from ROM/RAM and data
accesses to RAM, UART (`0x20000`), timer (`0x20001`), hart control (`0x20002`),
perf (`0x20003`), interrupt controller (`0x20004`), DMA (`0x30000`) and NPU
(`0x40000`). Any other native access retires with `result = 0` and no fault.

## 3. Instruction set

RV32IMA: base integer, `M` multiply/divide and `A` atomics. `A` (LR/SC and all
word AMOs) is implemented by the Aster-owned atomic fabric/PCPI adapter, not the
vendor core. Compressed instructions are disabled.

Xasterdot8 (Phase 8) is a packed signed-INT8 dot product: two register operands
each hold four signed 8-bit lanes; the four products are summed into a 32-bit
result with explicit modulo-2³² accumulation. It is issued through the pinned
PicoRV32 PCPI path as custom-0 `opcode=0x0b`, `funct3=0`, `funct7=0`. The
software macro is `.insn r 0x0b, 0, 0, rd, rs1, rs2`.

## 4. Core, fabric and coherence

- Each hart is an Aster-owned `aster_picorv32` wrapper around the pinned
  `vendor/picorv32`. The core is replaced without touching the fabric.
- The core exposes one held native memory port:
  `mem_valid, mem_instr, mem_addr, mem_wdata, mem_wstrb` →
  `mem_ready, mem_rdata`.
- The atomic fabric serializes native and atomic requests from both harts,
  enforces the permitted-address list, implements LR/SC reservations and AMOs,
  and detects faults.
- Each hart has a private L1 I$ and D$. The D$ is an MSI-like snooping cache.
  Lines are `LINE_WORDS × 4` bytes, `LINE_COUNT` sets per way. Only
  `0x1000_0000–0x1001_0000` is cacheable; MMIO and the other hart's private
  window bypass the cache.
- Shared RAM is the only coherent backing store. There is no directory, no
  shared L2 and no write-back L2. Cache hits are not serialized.
- Store acknowledgement is the commit point observed by AsterBench.

## 5. Peripheral register maps

All MMIO is little-endian, 32-bit. Writes use byte strobes; reads are
combinational. Reserved offsets read zero.

### 5.1 UART `0x2000_0000`

| Offset | Name | Access | Meaning |
| ---: | --- | --- | --- |
| `0x00` | `TX` | W | push byte lane 0 to the TX FIFO |
| `0x04` | `STATUS` | R | bit 0 TX write-ready |

### 5.2 Machine timer `0x2000_1000` (ABI 1)

| Offset | Name | Access | Meaning |
| ---: | --- | --- | --- |
| `0x00/04` | `TIME_LO/HI` | R | free-running 64-bit `aclk` counter |
| `0x08/0c` | `COMPARE_LO/HI` | RW | 64-bit compare, byte-strobed merge |
| `0x10` | `CONTROL` | W | bit 0 enable, bit 1 clear pending (lane 0) |
| `0x14` | `STATUS` | R | bit 0 pending, bit 1 enabled |
| `0x18` | `ABI` | R | `1` |
| `0x1c` | `CLOCK_HZ` | R | configured nominal fabric frequency |

`TIME` wraps modulo 2⁶⁴. When enabled and `TIME` reaches `COMPARE`,
`STATUS.pending` sets and `timer_irq` asserts (level). Disabling does not clear
pending. See `docs/timer.md`.

### 5.3 Hart control `0x2000_2000`

| Offset | Name | Access | Meaning |
| ---: | --- | --- | --- |
| `0x00` | `OWNER` | R | owner of the current control read |
| `0x04` | `SECONDARY_RUN` | W | hart 0 starts/stops hart 1 (lane 0) |
| `0x08` | `HARTS` | R | configured hart count |
| `0x0c` | `RUN/TRAP` | R | `{trap, run}` per hart |
| `0x10` | `TO_HART1` | W | hart 0 mailbox word to hart 1 |
| `0x14` | `TO_HART0` | W | hart 1 mailbox word to hart 0 |
| `0x18` | `LIFECYCLE` | R | `{flush_active, stop_busy, stopped}` |
| `0x20` | `FAULT` | R | `{fault_valid, fault_cause}` for the reader |
| `0x24` | `FAULT_ADDR` | R | fault address |
| `0x28` | `FAULT_INSN` | R | fault instruction |

`0x2000_2000` is **not** an interrupt controller in v1.0; the controller is at
`0x2000_4000`.

### 5.4 Performance counters

Coherent per-hart perf (ABI 4) at `0x2000_3000 + hart*0x100`:

| Offset | Meaning |
| ---: | --- |
| `0x00–0x6c` | counters 0–13, each `lo` at `i*8` and `hi` at `i*8+4` |
| `0x80` | running |
| `0x84` | ABI `4` |
| `0x88` | `CLOCK_HZ` |
| `0x8c` | `{SYNC_MEMORY, ENABLE_L1}` |
| `0x90` | `LINE_WORDS` |
| `0x94` | `LINE_COUNT` |
| `0x98` | `MEMORY_WAIT_CYCLES` |
| `0x9c` | `14` (counter count) |

Command writes go to `0x2000_3080` with `wdata[7:0]`: `1` start, `2` freeze,
`4` resume. A single write broadcasts to every coherent and DMA perf block, so
the measurement window is common. Counter 0 is cycles, counter 1 retired, and
the rest cover memory transactions, cache accesses/misses, DMA bytes,
accelerator cycles, backing transactions, interventions, invalidations and
writebacks.

Legacy perf (ABI 2) at `0x2000_3000` uses the map in
`software/runtime/aster.h` (`ASTER_PERF_*`): eight counters at `0x00–0x3c`,
control at `0x38`, ABI at `0x48`, `CLOCK_HZ` at `0x4c`, flags at `0x50`,
geometry at `0x54–0x5c`. **This map differs from the coherent ABI 4 map**; the
two must not be mixed. Firmware selects the map for its SoC.

Xasterdot8 perf (ABI 6) at `0x2000_3200` decodes the low 12 bits: counters at
`0x200–0x23f`, running at `0x280`, ABI at `0x284`, geometry at `0x288–0x29c`,
`CLOCK_HZ` at `0x2a0`, instruction decode constants at `0x28c/0x290`.

### 5.5 DMA `0x3000_0000` (ABI 1)

| Offset | Name | Access | Meaning |
| ---: | --- | --- | --- |
| `0x000/004/008` | `SOURCE/DEST/LENGTH` | RW | byte-strobed descriptor |
| `0x00c` | `COMMAND` | W | `1` start, `2` abort, `4` ack (lane 0, hart 0) |
| `0x010` | `STATUS` | R | `{rejected, aborted, error, done, busy}` |
| `0x014` | `BYTES_DONE` | R | bytes transferred |
| `0x018` | `ERROR_CODE` | R | terminal error |
| `0x01c` | `ABI` | R | `1` |
| `0x020/024` | `JOB_CYCLES_LO/HI` | R | job duration |
| `0x028/02c` | `LIMIT_LO/HI` | R | `0x1000_0000` / `0x1000_8000` |

Source and destination must lie in shared RAM `0x1000_0000–0x1000_8000`.
Completion is polled; v1.0 also latches DMA completion as an interrupt source.

DMA perf (ABI 5) at `0x3000_0100`: counters at `0x100–0x16f`, running at
`0x180`, ABI at `0x184`, `CLOCK_HZ` at `0x188`, flags/geometry at `0x18c–0x198`.

### 5.7 Interrupt controller `0x2000_4000` (ABI 1)

| Offset | Name | Access | Meaning |
| ---: | --- | --- | --- |
| `0x00/04` | `ENABLE0/1` | RW | per-hart source enable mask |
| `0x08` | `PENDING` | RW1C | latched source bits; write 1 clears |
| `0x0c/10` | `ACTIVE0/1` | R | `PENDING & ENABLEN` |
| `0x14` | `RAISE` | W1S | set the software source bit |
| `0x18` | `ABI` | R | `1` |
| `0x1c` | `SOURCES` | R | `4` |

Sources: bit 0 timer, bit 1 DMA completion, bit 2 NPU done, bit 3 software.
Only byte lane 0 is meaningful. `irqN = |(PENDING & ENABLEN)`. See
`docs/interrupts.md`.

## 6. Interrupt model

- The PicoRV32 cores run with `ENABLE_IRQ=1`, `ENABLE_IRQ_QREGS=0`,
  `ENABLE_IRQ_TIMER=0`, `LATCHED_IRQ=0` and `MASKED_IRQ=0x0000_0006`.
- `QREGS` stays off so custom-0 `funct7=0` remains the Xasterdot8 instruction
  instead of `getq`. The q0/q1 alias lands on `gp`/`tp`; v1.0 firmware leaves
  `gp` unused and uses `tp` only for the startup hart id.
- `MASKED_IRQ` masks the upstream ebreak/buserror IRQs, so `ebreak` still traps.
- The IRQ vector is the upstream fixed `0x10`. `start.S` and
  `start_multicore.S` place `j aster_irq_handler` at `0x10`; the handler saves
  caller-saved registers, calls the weak `aster_irq_dispatch`, and returns with
  `retirq`. Firmware unmasks with `maskirq x0`.
- The controller is level-driven. The handler services the source, clears the
  controller bit (W1C) and, for the timer, clears the timer pending.

## 7. Clock, reset and lifecycle

- POR reset and host RUN are separate. `peripheral_resetn = resetn && !stopped`.
- The warm-stop module drains the fabric, flushes caches and preserves shared
  RAM. STOPPED is acknowledged only after drain/flush/reservation completion.
- A stopped system accepts ROM boot writes; CPU ROM writes are always forbidden.
- The FPGA baseline is 31.25 MHz (FCLK0). The bridge reports `CLOCK_HZ`.

## 9. Known limitations

These are deliberate v1.0 boundaries, not defects:

- **No shared L2.** Coherence is MSI-like over shared RAM. L2 organization and
  refill are a v2 / Phase 14 axis.
- **No interrupt priority, nesting or preemption.** A single level per hart; the
  handler services all enabled sources before returning.
- **No privileged trap/CSR interface, no MMU, no OS.** Bare-metal only.
- **Polling DMA completion.** Completion is pollable and also latched as an
  interrupt source, but there is no descriptor ring or scatter-gather.
- **Single outstanding native request per hart.** No out-of-order or
  multiple-issue execution.
- **Fixed 4×4 NPU.** No configurable geometry; CNN layers are tiled in software.
- **`QREGS` off.** Firmware must not use `gp`/`tp` for general data.
- **No RTL frequency optimization.** The FPGA baseline is 31.25 MHz; frequency
  is a Phase 14/16 axis.
- **No ASIC flow yet.** SKY130/OpenROAD is Phase 15/16.
- **Cache hits are not serialized**, so measured coherence costs are a lower
  bound relative to a directory protocol.
